# 技术观察正文补充

`reading-notes.json` 以 `content/articles.json` 中的稳定条目 ID 关联详细解读，不改变事件日期、原始事实、审阅状态与归档快照。

每项提供研究问题、至少三段机制拆解、三行设计对照、阅读重点和验证指标。具体方法要由条目原始来源支撑；编辑提出的实验与解释不能写成作者实测。对照表描述设计思路，不冒充统一基准结果。

可以为条目增加原作者配图，需有准确来源、简短署名、替代文本和与正文相关的读图说明。新增配图必须是已核对的文件地址；获取失败时保留原有方法示意，记录构建警告，不用不相关图片替代。

正文由 `tools/expand-observations.py` 在原静态详情页基础上生成。网页不展示内部修订记录、制作过程与 GPT 署名。主页卡片使用独立链接，旧 `#item/ID` 地址跳转到同一完整版。

新增条目应同步填写本文件的对应记录，随后运行现有构建和测试。只要未删除现有条目，其编号、原始数据和两篇独立深度报告均应保留。
